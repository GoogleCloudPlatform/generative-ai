Runtime Defense-in-Depth

Three runtime controls protecting autonomous agents on the Gemini Enterprise Agent Platform:

1. Model Armor (Edge AI Firewall)

Drops jailbreaks and prompt injections at ingress; scrubs credentials and PII at egress before model execution.

2. Semantic Governance Policies (SGP)

In-line LLM judge evaluates proposed tool actions (issue_refund) against natural-language business rules.

3. Agent Anomaly Detection (AAD) & Closed Loop

Detects multi-turn session drift (e.g. smurfing) and auto-synthesizes hot-reloaded fleet policies with zero downtime.

Enterprise Pattern

Why Cryptographic Identity is Essential in Part 2

Even with Model Armor and SGP active, an attacker with direct SQL access or a rogue internal DBA could attempt to bypass all agent logic and mutate the database ledger directly.

By enforcing asymmetric Cloud KMS signatures at the Database Guard layer:

  • The database only accepts writes signed by an authorized agent private key stored inside Cloud HSM.
  • The agent's private key never leaves KMS HSM hardware.
  • Continuous database audits immediately sound alarms if any row is tampered with out of band.
