## What this app does

You talk; Gemini talks back, in real time. The app has two modes, chosen from
the sidebar:

- **Avatar Studio** (`/`): the model answers as a talking avatar with a
  synthesized face.
- **Live Audio & Vision** (`/live`): voice only, with optional camera or screen
  sharing. See [Live Audio & Vision mode](#live-audio--vision-mode).

Worth understanding up front: **the avatar video is generated by the model
itself.** When you pick or upload an avatar image, that image is sent to Gemini
as a visual anchor, and the model returns a video stream of that character
speaking. Your browser is only decoding and playing it. There is no local
animation, so video quality and expressiveness are properties of the model, not
your hardware.

Audio and video arrive together in a single stream. Latency to first frame is
typically 1.5–2.5 seconds after you start a session.

## Starting a session

1. Open the app (locally, `http://localhost:5173`).
2. Choose an avatar (below).
3. Optionally adjust voice, language, and system instruction.
4. Click **Start Session**.
5. Grant microphone permission when the browser asks.

The avatar greets you as soon as the connection is ready — you don't need to
speak first. If you hear nothing after a few seconds, check the
[troubleshooting](#troubleshooting) table.

## Choosing an avatar

Four options:

### Presets

Eleven built-in personas, each with its own default voice, greeting, and
personality: **Jay, Paul, Sam, Ingrid, Kira, Vera, Ben, Kai, Leo, Carmen,
Piper**.

### Upload a photo

Any image file. It's automatically center-cropped to the required 9:16 portrait
shape at 720×1280, then re-synthesized into a stylized 2K character portrait
before being used as the avatar anchor.

Best results come from a clear, front-facing, well-lit headshot with the face
roughly centered.

### Webcam capture

Same pipeline as upload, but you take the picture in-app. Useful for putting
yourself on screen as the avatar.

### Generate from a prompt

Describe a character in text and the image model creates the anchor. Be
specific about framing — "head and shoulders portrait, facing camera" produces
far better results than a scene description, because the anchor needs to be a
portrait to animate well.

## Live Audio & Vision mode

Open **Live Audio** in the sidebar (or go to `/live`) for a voice conversation
without an avatar. Pick an optional persona, a voice, and tools (Google Search,
info cards), then **Start Live Session**. An audio-reactive visualizer shows
when Gemini is speaking or listening. The voice button in the session header
mutes Gemini's audio while the visualizer keeps reacting. Camera, screen
sharing, transcripts and **End Session** work as in avatar mode.

## Voice and language

- **Voice** — around 30 prebuilt voices are available. Each preset has a
  sensible default; override it if you like. Voice and persona are independent,
  so any voice can be paired with any avatar.
- **Language** — sets both the spoken output language and the transcription
  language. Defaults to `en-US`.

Changing either requires starting a new session; they're fixed for the lifetime
of a connection.

## During a session

### Talking and interrupting

Just speak. The model detects when you start and stop — there's no
push-to-talk.

**You can interrupt.** Start speaking while the avatar is talking and it stops
immediately, discarding whatever it had buffered. This is the main thing that
makes the interaction feel conversational rather than turn-based.

### Transcripts

Both sides of the conversation appear in the transcript panel as they're
spoken. Text appears progressively while speech is still in progress, so
partial sentences updating in place is expected behavior, not a glitch.

On mobile the transcript is behind a tab switcher to keep the video full-size.

### Camera / vision

Toggle your camera on during a session and the model can see what you show it —
hold up an object, point at a screen, show a document.

Your local preview runs smoothly at full frame rate, but frames are only sent to
the model **once per second**. That's deliberate: it's the documented rate for
Live API vision input and it keeps bandwidth reasonable. So the model's
awareness of what you're showing lags by up to a second.

### Ending the session

Use **End Session** rather than closing the tab. It gives the avatar a moment
to say goodbye and closes the connection cleanly. If the avatar is mid-sentence
it will be interrupted, deliver the goodbye, and then disconnect.

## Settings

The settings panel persists to your browser's `localStorage`.

| Setting               | Effect                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------- |
| System instruction    | Overrides the persona's personality and behavior                                            |
| Welcome message       | Overrides the greeting                                                                      |
| Voice                 | Overrides the persona default                                                               |
| Live model            | Switches the Gemini Live model for the session                                              |
| Region                | `us-central1` or `global`                                                                   |
| Image model           | Which model synthesizes custom avatars                                                      |
| Voice detection (VAD) | Tunes when the model thinks you've started and stopped talking                              |
| Live capabilities     | Context window compression, proactive audio, speech adaptation phrases, sampling parameters |
| Theme                 | Light, dark, or match your system                                                           |

### Voice detection

If turn-taking feels wrong, these four controls are what to reach for. All are
blank by default, meaning the server decides; anything you set is sent as an
explicit override.

| Control                     | Try raising it when                                   | Try lowering it when                          |
| --------------------------- | ----------------------------------------------------- | --------------------------------------------- |
| Start of speech sensitivity | Interrupting the avatar feels sluggish                | Background noise keeps cutting the avatar off |
| End of speech sensitivity   | Replies feel slow to arrive                           | You get cut off mid-thought                   |
| Silence duration (ms)       | You need more thinking time before the model responds | Replies feel laggy                            |
| Prefix padding (ms)         | Your first word or two gets clipped                   | —                                             |

Changes apply to the next session you start, not the current one.

Model and region overrides are useful when a particular preview model is
unavailable or misbehaving — see [limits](#limits-and-expectations).

## Limits and expectations

- **Sessions end at just under 10 minutes.** A warning appears as the limit
  approaches. This is a deliberate guardrail; start a new session to continue.
  Conversation history does **not** carry across sessions.
- **Preview models.** This app targets preview Gemini Live models. They change
  without notice, and availability varies by project and region. Errors on
  connect are frequently access or model-availability issues rather than bugs.
- **Video quality is fixed.** Resolution and frame rate are decided by the
  model; there's no quality setting.
- **One conversation at a time** per browser tab.

## Troubleshooting

| Symptom                                      | What's happening                                                                         | What to do                                                          |
| -------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Session won't start; error immediately       | Model or modality unsupported for your project, or not allowlisted for the preview model | Try a different Live model in Settings                              |
| Connects, then drops with a policy violation | The avatar reference image was blocked by a safety filter                                | Use a different avatar or photo                                     |
| Custom avatar rejected                       | Image isn't a compliant 9:16 PNG at ≥704×1280                                            | Re-upload as PNG; avoid WebP                                        |
| No audio, video plays                        | Browser tab is muted, or output device is wrong                                          | Check the tab mute state and system output device                   |
| Audio plays, video is black                  | Codec negotiation failed                                                                 | Try another browser; report with the browser console output         |
| Avatar talks over you                        | Interruption isn't reaching the server                                                   | Check mic permission and that input levels are registering          |
| Avatar never greets you                      | Session didn't reach ready state                                                         | Check the browser console and the backend log for connection errors |
| Choppy audio                                 | Network, or CPU contention                                                               | Close other tabs; check connection stability                        |
| Model can't see what you're showing          | Camera is off, or you moved too fast                                                     | Confirm camera is enabled; hold objects still for ~2 seconds        |

If you're running locally and the frontend won't start at all, you probably
skipped `npm install` in `frontend/` — see the
[quickstart](../README.md#quickstart).
