# Gemini Live Studio

|           |                                             |
| --------- | ------------------------------------------- |
| Author(s) | [G. H. Chinoy](https://github.com/ghchinoy) |

A reference app for the **Gemini Live API**: a web UI backed by a small Go
server that proxies real-time, bidirectional sessions. It shows the pattern
end-to-end: browser audio and camera capture, a secure server-side session,
streamed media back to the browser, barge-in, transcripts, tool calls, and
clean teardown.

It has two modes, served by the same session code:

- **Avatar Studio** (`/`): talk to a generated talking avatar. The model returns
  fragmented MP4 video with the audio muxed in; the browser plays it through
  `MediaSource`. Use one of 11 preset personas or create your own avatar from
  a photo, a webcam capture, or a text prompt.
- **Live Audio & Vision** (`/live`): voice conversation with optional camera or
  screen sharing, no avatar. The model returns 24 kHz PCM audio, shown with an
  audio-reactive visualizer.

The avatar video is generated by the model itself: there is no lip-sync rig,
sprite sheet or 3D engine.

## Why a Go server

The browser never holds credentials. The Go server authenticates to Google
Cloud with Application Default Credentials and owns each upstream Live session.
Its job, per browser connection:

1. Check the request origin and size limits, then validate the session config
   (models and locations come from allowlists).
2. Open the Live session and prompt the model to greet the user first.
3. Relay browser audio, camera frames and text upstream, and relay model media,
   transcripts, interruptions and tool calls back down.
4. End the session cleanly: a spoken goodbye on **End Session**, a warning
   before the 10-minute limit, and a single shutdown path that closes both
   sockets on every exit.

The same pattern works for any Live API frontend; the server is about 1,600
lines of Go (excluding comments and tests), with tests for every exit path.

## Features

- **Real-time audio and video.** 16 kHz PCM is captured off the main thread
  with an `AudioWorkletNode`; fragmented MP4 (avatar mode) or PCM (audio mode)
  streams back, with video codecs read from the first fragment.
- **Barge-in.** Interrupting the model flushes already-buffered media at once.
- **Live transcripts** for both sides, from the Live API native speech
  recognition.
- **Realtime vision.** Share your camera or screen; frames are sampled at 1 FPS
  while the local preview stays smooth.
- **Custom avatars** from a photo, webcam capture or text prompt, cropped to
  `9:16` and generated as a 2K portrait with a Gemini image model.
- **Tools and grounding.** Google Search grounding, an example function-calling
  tool (`show_info_card`) shown in the transcript, and reference material from
  pasted text, files or images.
- **Tunable sessions** from Settings: model and region, voice activity
  detection, context window compression, proactive audio, sampling parameters.
- **Accessible, themeable UI.** Lit web components with a small design system,
  light and dark themes, keyboard navigation, and automated accessibility
  checks.

## Quickstart

### Prerequisites

| Requirement                                             | Version | Notes                                                             |
| ------------------------------------------------------- | ------- | ----------------------------------------------------------------- |
| [Go](https://go.dev/doc/install)                        | 1.26+   | see `go.mod`                                                      |
| [Node.js](https://nodejs.org/en/download/)              | 22.18+  | for the Vite frontend                                             |
| [gcloud CLI](https://cloud.google.com/sdk/docs/install) | any     | for Application Default Credentials                               |
| Google Cloud project                                    | n/a     | with the Gemini Enterprise Agent Platform (Vertex AI) API enabled |

> **Access note:** the avatar surface (`VIDEO` response modality) and custom
> avatars may require your project to be allowlisted. Without access, sessions
> close with WebSocket code `1007` or `1008`. Audio mode (`/live`) works with
> the generally available Live model.

### 1. Install

From this directory:

```bash
go mod download
(cd frontend && npm install)
```

### 2. Authenticate

The server uses Application Default Credentials; there are no API keys.

```bash
gcloud auth application-default login
gcloud config set project YOUR_PROJECT_ID
```

### 3. Configure

```bash
cp .env.example .env
```

```env
GOOGLE_CLOUD_PROJECT=your-project-id
GOOGLE_CLOUD_LOCATION=us-central1
GEMINI_LIVE_MODEL=gemini-3.8-live
GEMINI_IMAGE_MODEL=gemini-nano-banana-2.1
GEMINI_IMAGE_LOCATION=global
```

`GOOGLE_CLOUD_PROJECT` is required; everything else has a default (see
[Configuration](#configuration)).

### 4. Run

```bash
make dev
```

This starts the Go server on `localhost:8080` and the Vite dev server on
`localhost:5173`. Open **<http://localhost:5173>**. Run `make help` to list
every target.

## Using the app

1. **Choose a mode**: Avatar Studio or Live Audio from the sidebar.
2. **Set up the session**: pick an avatar or persona, a voice, and optional
   tools or reference material.
3. **Start talking.** The assistant greets you first. Interrupt whenever you
   like.
4. **Optionally share your camera or screen** so the model can see it.
5. **End the session** with **End Session**; the assistant says goodbye before
   the connection closes.

See the [User Guide](docs/user_guide.md) for details.

## Configuration

All configuration is through environment variables, read from `.env` at
startup (the `.env` file takes precedence over the shell).

| Variable                | Default                  | Purpose                                                                                                                                                                                            |
| ----------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GOOGLE_CLOUD_PROJECT`  | (none)                   | **Required.** Project ID.                                                                                                                                                                          |
| `GOOGLE_CLOUD_LOCATION` | `us-central1`            | Region for Live sessions.                                                                                                                                                                          |
| `GEMINI_LIVE_MODEL`     | `gemini-3.8-live`        | Live model. Avatar mode needs a model that streams fMP4 video with `AvatarConfig`.                                                                                                                 |
| `GEMINI_IMAGE_MODEL`    | `gemini-nano-banana-2.1` | Avatar image generation model.                                                                                                                                                                     |
| `GEMINI_IMAGE_LOCATION` | `global`                 | Location for image generation (image models are served from `global`).                                                                                                                             |
| `GEMINI_TEXT_MODEL`     | `gemini-3-flash-preview` | Model that describes uploaded reference images.                                                                                                                                                    |
| `GEMINI_BASE_URL`       | unset                    | Override the API endpoint.                                                                                                                                                                         |
| `PORT`                  | `8080`                   | Server listen port.                                                                                                                                                                                |
| `LOG_LEVEL`             | `info`                   | `debug` adds per-message session logs (sizes and turn signals, never transcript text). JSON with Cloud Logging fields on Cloud Run, text elsewhere.                                                |
| `ALLOWED_ORIGINS`       | unset                    | Extra browser origins (comma-separated `scheme://host[:port]`) allowed to call `/api/*` and open the WebSockets. Same-origin and loopback development are always allowed; other origins get `403`. |

Model, region and image model can also be chosen per session in **Settings**.
The server accepts only values from the allowlists in `models.go` (plus its own
defaults); anything else falls back to the default.

## Deployment

```bash
make build             # Go binary + frontend bundle
make container-build   # container image from the Dockerfile
```

Deploy to Cloud Run with the included script:

```bash
# Preview the resolved configuration and gcloud commands; nothing is deployed
scripts/deploy.sh --dry-run --project my-project

# Deploy (shows the plan and asks for confirmation)
scripts/deploy.sh --project my-project
```

Settings resolve in this order: flag, environment variable, `.env`, then
defaults. A new deployment is **public** unless you put it behind
Identity-Aware Proxy (IAP):

```bash
# Behind IAP, granting access to a group and individual users
scripts/deploy.sh --project my-project --iap \
  --iap-group team@example.com --iap-users alice@example.com,bob@example.com

# Redeploy an IAP service without changing who has access
scripts/deploy.sh --project my-project --iap
```

IAP access is only ever added, never removed (use
`gcloud iap web remove-iam-policy-binding` to revoke). Redeploying a service
that already uses IAP keeps IAP even without `--iap`; pass `--no-iap` to make
it public. Each plan and `--dry-run` lists the current IAP members. Reusable
settings can be saved as profiles in `scripts/profiles/<name>.env`. Run
`scripts/deploy.sh --help` for every option.

## Project layout

```text

```

## Troubleshooting

| Symptom                                     | Cause and fix                                                                                                                |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Server exits at startup                     | `GOOGLE_CLOUD_PROJECT` is unset.                                                                                             |
| `401`/`403` from the API                    | Run `gcloud auth application-default login`.                                                                                 |
| WebSocket closes with `1007`                | Invalid session settings, or a model or modality your project can't use. Try a different `GEMINI_LIVE_MODEL`, or audio mode. |
| WebSocket closes with `1008`                | The avatar reference image was blocked by a safety filter. Try another image or preset.                                      |
| Upgrade fails with `403`                    | The page is served from another origin. Serve it from the Go server or set `ALLOWED_ORIGINS`.                                |
| A preset shows a letter in place of a photo | That preset's thumbnail is no longer hosted; the preset still works.                                                         |
| Black video, audio only                     | Codec negotiation failed. Check the browser console for the `media_config` event and `MediaSource.isTypeSupported`.          |
| Custom avatar rejected                      | Reference images must be PNG or JPEG, `9:16`, at least `704x1280`.                                                           |
| Session ends at about 10 minutes            | Expected: a deliberate guardrail before the Live API session limit.                                                          |
| Frontend won't start                        | Run `npm install` in `frontend/`.                                                                                            |
