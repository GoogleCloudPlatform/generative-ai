ACME Cloud: protecting a server

Verified boot

Verified boot only lets boot software signed by a trusted key run, which protects against boot-level malware. Turn it on for every internet-facing server. It's in the Protection step when you launch a server.

Integrity alerts

Integrity alerts warn you if the boot sequence changes unexpectedly. They are on by default.

Encryption

All volumes are encrypted. Turn on Encrypt volumes with your own key if your policies require customer-managed keys.

Network access

Only open the ports you need. Public web servers need HTTP (80) and HTTPS (443). Avoid SSH from anywhere in production; use a private network or a bastion instead.

Turn on Deletion lock for production servers so they can't be deleted by mistake.
