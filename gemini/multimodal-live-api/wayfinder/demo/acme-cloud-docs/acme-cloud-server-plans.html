ACME Cloud: choosing a server plan

Every ACME Cloud server runs on a plan. Plans are grouped into four families.

Family Best for Plans
Standard Web servers, APIs, small databases S2 (2 vCPU, 4 GB), S4 (4 vCPU, 16 GB), S8 (8 vCPU, 32 GB)
Compute Batch jobs, video encoding, CPU-bound services C4, C8, C16
Memory In-memory caches and analytics M4 (32 GB), M8 (64 GB)
GPU Machine learning inference and rendering G1 (1 GPU), G2 (2 GPUs)

Recommendations

  • A production web server usually starts on Standard S4 in the region closest to its users.
  • Choose Memory plans for in-memory databases such as caches.
  • You can change plans later; the server restarts during the change.

Regions

ACME Cloud offers four regions: US East, US West, EU Central, and Asia Pacific South. Each region has two or three datacenters. There is no region called US East 2 or EU North.

ACME Cloud is a fictional product used for demos.
