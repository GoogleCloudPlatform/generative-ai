ACME Cloud: pricing models

On-demand

Pay per hour with no commitment. On-demand servers are never interrupted. Use on-demand for production workloads.

Flex

Flex servers cost about 60% less than on-demand, but ACME Cloud can reclaim them with 30 seconds' notice when capacity is needed. Use Flex for batch jobs, CI runners, and other work that can restart.

Other costs

  • Boot volumes are billed per GB per month: Standard SSD $0.10, Fast SSD $0.17, Hard disk $0.04.
  • Daily snapshots cost about half the volume price; weekly snapshots about a quarter.
  • A static (reserved) public IP costs $3.50 per month. Ephemeral IPs are free.

ACME Cloud is a fictional product used for demos.
